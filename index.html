Como funciona
• Fitbit: ligação direta via OAuth. Crie app em dev.fitbit.com e cole o Client ID.
• Amazfit / Zepp: não há API pública simples para web. Na app Zepp: Perfil → Definições → Direitos do utilizador → Exportar dados (ZIP com CSV). Treinos individuais: exportar GPX. Depois importe na página Adicionar.
• Google Fit: API Web em descontinuação. Use CSV ou Health Connect.
• Apple Health: bloqueado em websites/PWAs.
• Balanças: CSV (Runstar, Xiaomi, Renpho, etc.).
Configuração Fitbit

1. Vá a dev.fitbit.com/apps → Register a new app
2. OAuth 2.0 Application Type: Client
3. Callback URL: copie o Redirect URI acima
4. Scopes: weight, profile
5. Cole o Client ID e clique em Ligar
